02 · QUICK REFERENCE

Studio notes.

Small reminders that are useful while drawing, calculating and preparing presentation boards.

TOPOGRAPHY

Slope

slope % = rise / run × 100

1:20 = 5% · 1:12.5 = 8% · 1:10 = 10%

PLANTING

Area planting

quantity ≈ area / spacing²

Add a small replacement allowance when ordering plants.

EARTHWORK

Volume

m³ = area × depth

Convert depth from centimeters to meters before calculating.

RAINWATER

Simple conversion

1 mm × 1 m² ≈ 1 L

Apply an efficiency factor for real-world losses.

PRESENTATION

Visual hierarchy

1 dominant + 2–4 supporting

Let one plan, map or render clearly dominate each board.

WORKFLOW

Project logic

analysis → concept → design → detail

Make the relationship between these stages visible in your presentation.

03 · ABOUT

Built for landscape architecture students.

Landscape Architecture Toolkit is a small collection of practical browser tools for early calculations, studio work and presentation preparation.

It is intentionally lightweight: plain HTML, CSS and JavaScript, so it can be hosted directly on GitHub Pages and expanded over time.
